## À propos

*Copyright Infringement* est un EP de **uchuuj1n**, publié sous forme de page web statique (GitHub Pages) : un lecteur audio avec disque animé, tracklist et notes de samples pour chaque morceau.

## Fonctionnalités

- Lecteur de l'EP (`index.html`) : lecture/pause, stop, précédent/suivant, barre de progression, volume, tracklist cliquable, note de samples affichée par morceau
- `cyberdeck-player.html` : variante du lecteur où l'on ajoute ses propres fichiers audio (sélection de fichiers locaux)

## Utilisation

Ouvrir la [page en ligne](https://elisalien.github.io/copyrightinfrigement/), ou en local ouvrir `index.html` dans un navigateur (les MP3 sont dans `mp3/`).

## Structure du projet

| Fichier / dossier | Rôle |
|-------------------|------|
| `index.html` | Lecteur de l'EP avec la tracklist |
| `cyberdeck-player.html` | Lecteur générique pour fichiers audio locaux |
| `mp3/` | Morceaux de l'EP (les sources WAV ne sont pas versionnées) |
| `_config.yml` | Configuration GitHub Pages (titre, description) |

## Stack technique

HTML, CSS, JavaScript (sans dépendance), polices Google Fonts (Orbitron, Share Tech Mono), GitHub Pages.
